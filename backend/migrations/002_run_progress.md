# 002 运行断点进度列

`runs` 增加 `progress` JSON 列，保存后台计算的断点进度（已算完的分支与当前领先候选），
供后台中断后从未算完的分支续跑。应用启动时通过 `src.config.database.migrate()` 幂等执行
`ALTER TABLE runs ADD COLUMN progress JSON`，新建与既有数据库均适用。

- 断点只用于续跑，不通过接口暴露，筛查页面等计算完成后才展示榜单与两组命中单号。
- 只有持有当前租约的尝试可以写入断点或结果，并发重试的其余写入一律作废，同次筛查只生效一次。
- 运行结束（完成、失败或多次中断）时清空该列。
